CX AUDIO OUTPUT 本地串流 · 不上传云端 v1.2.0

快速开始

三步，让声音走起来。

01

保持串流开启

CX Audio Output 会捕获 Windows 默认输出设备的系统声音。开始播放音乐、视频或游戏即可。

02

让设备加入

扫描二维码，或输入访问码。手机和电脑需要连接同一个 Wi-Fi 或局域网。

03

点击开始聆听

浏览器需要一次点击才能播放声音。之后可以调节音量、查看缓冲与网络延迟。

电脑本机仍会发声

串流会把声音复制给其他设备，但不会关闭电脑本机的扬声器。如果只想让其他设备发声，请调低电脑音量，或把默认输出切换到一个未使用的设备。

其他设备无法连接？

首次运行时请在 Windows 防火墙提示中选择“允许访问”，并勾选“专用网络”。也可以管理员身份运行：

New-NetFirewallRule -DisplayName "CX Audio Output" -Direction Inbound -Protocol TCP -LocalPort 5240 -Action Allow -Profile Private
访问码每次启动都会更新。关闭此窗口不会中断串流。
